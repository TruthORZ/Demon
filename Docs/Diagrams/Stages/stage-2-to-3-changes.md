## 稳定部分与必须说明的边界

- 23 份运行时脚本字节完全一致，包括 `ListeningTool`、`CipherWheel`、`RegionEntryLatch`、`SceneContracts`、`ExplorationGuidance` 以及若干配置/交互组件，见下方完整文件表。
- `GameSession`、`RuneBoardModel`、密码锁、运动规则与发现进度继续承担原本职责，同时增加状态捕获/恢复；`GameClock` 也增加跨日前裁决。它们属于修改并复用。
- 旧主线允许连续睡眠。新完整主线有每日事项和夜间门槛，并且 D8 不能睡过结局。该行为由新需求明确改变，演示时说明旧规则入口的兼容与新主线约束。
- 新增协调组件 `CompletePlaythrough` 持有多个模块并编排主线。它让规则与部分 UI 保持分工，也增加协调层集中度；这是一项需要解释的实际取舍。
- 当天快照仅存在于当前进程。玩家重试与 F8 调试重放分别使用实际入口快照与前序补齐，展示时区分两条用途。
