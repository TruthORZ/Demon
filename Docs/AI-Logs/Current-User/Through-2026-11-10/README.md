# Demon 项目 AI 对话记录导出

## 如何阅读

解压 ZIP 后，双击 index.html。可按聊天阅读，也可打开 all-conversations.html 按时间阅读全部记录并搜索。无需联网。Markdown 和纯文本可用常见文本编辑器打开，JSONL 保留逐条结构化内容与来源行号。

## 范围

用户已确认：Codex 左侧 Demon 项目的全部聊天，截止北京时间 2026-11-10 24:00，即 2026-11-11 00:00 +08:00，对应 UTC 2026-11-10T16:00:00.000Z。时间严格小于该边界。按原始消息/展示事件完成时间截取；交互提问按原调用记录时间截取。同一聊天后续消息单独排除，而非按整段聊天日期判断。

聊天标题保留应用原名。原生工具清点 58 个活动、21 个归档聊天，8 个匹配 Demon 项目 ID 或精确工作区；其中 6 个有截止时间前的记录，“模型”和“5”晚于截止时间。“5”的应用 projectId 为空，但工作区精确匹配，故仍列入范围清单。没有导出其他项目的聊天。

## 内容真实性

正文来自本机原始会话记录中的 UserMessage / AgentMessage，不重写、不翻译、不摘要。包含用户在交互确认界面给出的回答，以及 AI 的原始交互提问。JSONL 保留消息 ID、UTC 与本地时间、来源文件和行号、正文 SHA256。消息完成事件与底层 assistant 原文另作精确文本核对。它是对话原文导出，不是重建聊天截图。

## 明确排除

不包含截止时间后的内容、内部推理、系统/开发者指令、自动注入的环境与上下文、压缩上下文摘要、Token 统计及工具内部命令/输出。它们不作为用户与 AI 的正文。工具产生的代码改动仍以 Git 历史为依据。本次未提交或推送任何内容。

## 附件

优先恢复记录中内嵌的用户图片原始字节，其余可访问的用户附件与 ImageView 图片复制导出时本地文件。附件不改图。当前文件可能在对话发生后被修改，attachments-manifest.json 标注来源、修改时间与 SHA256，不将其冒充历史文件快照。无法找到的文件列出原路径并标记缺失，没有补造。正文中的原始绝对路径照原文保留，打包附件另列相对路径便于离线打开。

## 原图恢复及引用标记

同时恢复了原始工具输出中内嵌的图片，避免依赖已经删除的临时截图文件。单图调用可以明确对应原路径；同一调用包含多张图时，作为原始附件组保留，并明确说明未推断各路径与图片的一一对应关系。

应用的可见回复正文会移除 oai-mem-citation 机器引用容器。本次核对仅对这种容器作排除，正文仍逐字匹配；JSONL 的 originalAssistantResponseText 另存包含原始引用标记的完整底层回复，供核查。
