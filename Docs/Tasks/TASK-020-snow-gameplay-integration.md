## 执行步骤

1. 建立可恢复基线。记录 Git HEAD、未提交文件和两个源场景，确认 Unity 已保存且处于编辑模式。检查床、房门、木屋地面和周边岸线，找出能走到的测试点。
2. 用 Unity 编辑器创建 `Assets/Demon/Scenes/DemonNineDay_Art.unity`。以 Snow 的地形、木屋、水面和美术设置为环境，成组迁移九天系统对象，保留组件、预制体链接和引用。对照原场景筛掉重复灰盒地面、阻挡物、相机与太阳。玩家相机沿用现有输入，门接现有 E 交互，日夜由原时钟驱动。
3. 在层级中分组摆放床边出生与睡眠、室内交互、户外观察与探索、湖岸取板及追逐点。相关的近景机位、碰撞和交互组件跟随各自的对象移动。电台、太阳参照和风向标分别保留给轮盘的显式引用。按新布局检查室内道具视线、箱盖及挂钟镜头。
4. 按新地图烘焙独立导航资产，检查湖岸、回屋路线和追逐退开点。导航资产使用专用二进制 Git 规则，防止换行转换。移动墙、门口、地面等影响路径的对象后重烘焙；移动 T07 后检查其可站立范围、拾取镜头和回程。
5. 首轮在保存重开后的整合场景验证 D1 床边出发、进出木屋、观察与睡眠、D2 找到并阅读 T01，以及 D8 指定时段才可拾取、按住 E、带回木屋、安放并进入拼板。另确认原场景可继续运行。临时移动一个代表性交互点，确认功能随动后恢复位置。
6. 后续在整合场景验证 D3–D7 的线索、追逐、声音、风铃、光束和永夜，接完 D8 的封湖、读箱与 D9 结局。完整正常路线与跳过路线通过后，再确定构建入口和美术交接。

## 人工调整约定

- 在编辑模式下移动带交互组件的完整对象。道具自带的 Collider 和子机位会随父对象移动；如果机位单独存放，按 Inspector 的引用找到并同步调整。保留原对象可以保留已有接线。
- 床边出生点与睡眠点是不同用途。改木屋床位时一并检查二者，确保玩家醒来站在地面上，床可以从正常站位交互。
- 轮盘、三个地标可移动。移动后验算数字，并检查玩家能从轮盘看懂方位提示。改动道路、障碍、取板点或追逐点后重新验证可达性。
- 按层级拖动 `T07_Table_Editable` 可一起移动空台和放置后的石板。拖动 `T07_Shore_Editable` 可一起移动拾取物、近景镜头和岸边台座。D2 的洞内石板随 `Cave_Editable` 移动，沿途脚印和引导节点单独调整。
- 改木屋朝向、房门或台阶时，一并对齐 `Cabin_Doorway_Navigation` 和 `Cabin_Stairs_Navigation` 的起止点，重新验证室内外通行。摆放物可以单独移动；地形雕刻会修改与源场景共用的 TerrainData。
