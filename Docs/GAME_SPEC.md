# Demon 游戏设计规范

Updated: 2026-10-28 Asia/Shanghai
状态：已确认设计基线。本轮取消+1，采用自然跨日循环与午夜挂钟结局。实际完成程度见[ARCHITECTURE](ARCHITECTURE.md)，当前实施见[TASK-005](Tasks/TASK-005-no-plus-one-finale.md)。

## 1 定位与制作约束

Windows第一人称键鼠雪地恐怖解谜。玩家独自在监测站值守，九天内观察世界、理解符文、使用监测与牵制工具，最后尝试封湖，却因误读循环再次开启封印。保留小屋、工具棚、湖岸、雪林、山洞与邪教仪式方向，不采用无线电求救者身份骗局。

团队为策划一名、技术美术一名，Codex负责程序与技术。用于课程展示；最初约定制作周期剩余三周，具体提交日期与剩余排期待确认，不能随文档更新自动重置周期。游玩总时长无固定指标，不能直接用九天乘24分钟推导。

首个可玩版本使用简单几何占位；场景、模型、镜头、UI、材质、音频和可调参数保存为Unity资产。具体展示电脑配置待确认。

## 2 故事、能力与威胁边界

第一夜暴风雪中邪教徒开启湖中封印，五块封印石板散落。恶魔投影能影响现实，但尚无正式降临的实体。玩家原定第八天交班，接班者没有到来，原因待定。

恶魔配合制造第八天争夺T07的假象，不代表它能自行重构石板。投影可影响的具体实物、接触符文与不能自己修复的原因仍待细化。

无玩家伤害、生命值或死亡。恶魔通过巨大雪地脚印、声音、照明干扰和黑影等产生威胁。追近可打断拾取，玩家仍保留进度；具体打断反馈、距离与冷却待制作验证。D3才获得运动，D5才获得声音，D7才获得光；不提前使用对应主动能力。D2跟随的是邪教徒的人类脚印。

湖中黑影早期只在夜间或下雪时偶尔出现，随着能力解封靠近湖岸；D7后常驻。引导符文发光不等于可转移的LIGHT属性。

## 3 按日期推进的流程

| 日期 | 关键流程 | 机制与理解 | 世界状态与恐怖表现 |
| --- | --- | --- | --- |
| D1 建立日常 | 熟悉小屋、工具棚、湖岸、值守工作、电台与风向标。发现有三位密码锁的箱子A、数字轮盘；发现无机械锁却打不开的箱子B。夜间邪教徒开启湖中封印。 | 记住设施正常声音、运动和空间位置；不要求此时解箱。 | 白天建立正常参照。第一夜后投影可影响现实；是否直接展示开封印待定。 |
| D2 发现预告 | 搜寻得到T01；沿人类脚印找到山洞与邪教仪式痕迹。 | T01预告D3将风向标的运动TRANSFER给恶魔，先发现、后验证。 | 湖中黑影远距离、短暂出现；不提前出现恶魔运动造成的巨大脚印。 |
| D3 预告成真 | 零点T01生效；调查异常，发现T02；第一次雪地追逐。 | 有风时风向标仍静止。T02预告D5交换电台与恶魔的声音。 | 巨大雪地脚印接近，靠踏雪等环境反馈表现追逐；尚不使用恶魔主动说话或模仿人声。 |
| D4 观察推理 | 调查湖岸、雪林、仪式遗迹，发现T03，具体搜寻任务待细化。 | T03预告D7将太阳的光TRANSFER给恶魔；太阳符号此时可以尚未被准确理解。 | 保留喘息和推理，观察风向标与脚印的持续变化；不重复堆叠同类追逐。 |
| D5 声音失去可信度 | 零点T02生效；发现T04，得知D9恶魔获得实体。 | 湖中传出原电台的声音，电台出现交换后的异常声音。理解日期程序具有明确后果。 | 熟悉广播来自错误位置；恶魔主动发声、模仿等从此阶段开始。 |
| D6 有限的预警 | 正常搜寻获得并补全T05，启用林中特殊风铃；不跳日，当天体验监听。 | 恶魔进入某风铃区域时报警一次，离开后重新监听；已知位置/音色帮助估计区域。 | 先看见脚印经过以验证，再在遮挡处只听到风铃。响声停止不等于安全，工具不提供精确实时坐标。 |
| D7 永夜与牵制 | 零点T03生效。理解太阳符号，对照轮盘解开A得到T06。学习运动交换与光束牵制。 | 稳定照住恶魔可辨认区域，交换恶魔与风向标的运动；失锁后再次交换复位。先安全观察效果，再实际使用。 | 零点湖中异光出现；预期日出时太阳只剩白边，没有正常日光，进入永夜。脚印停止时风向标转动；光束移开后恢复追逐。 |
| D8 白天 等待落空 | 接班未到；检查交接信息与已有线索，明确取得T07、封湖和打开B的动机。 | 巩固风铃定位区域、光束争取行动时间的分工。 | 用挂钟/日期记录区分永夜中的时段；保留整理与准备空间。 |
| D8 夜间 错误的成功 | T07到指定夜间才出现。用风铃和光束在追逐中取得它，回棚补全目标程序，交换B与湖的封闭属性；打开B阅读真相。 | 以为完成IF DAY <= 9，实际是带9→3返回的WHILE。固化后立即交换一次，B解封、湖封闭。拾取要求短暂转移光束。 | 恶魔配合争夺假象。封湖后湖光熄灭，威胁暂退，先制造成功感；箱内文字揭示返回线路与循环，未出现+1或时间魔法。 |
| D9 零点 理解得太晚 | 读完关键文本后转向挂钟，看指针到12点；T04赋实体，T07第二次交换。 | B封闭、湖开启；同一零点先处理赋实体和交换，再按实体且开湖判定降临。 | 石板再次发光，箱盖猛合，湖光重亮，恶魔正式降临。固化程序已无法撤销。 |

D7之后永夜不等于世界时钟停止。D8夜间的开放条件由日期和时刻判定，不以画面是否黑暗判断。

## 4 七块石板的身份与程序

总编号用于沟通与发现顺序，封印编号只说明五块封印的身份。T07就是第五封印，不额外增加另一块等待OPEN的石板。

| 总编号 | 身份/取得 | 条件与效果 |
| --- | --- | --- |
| T01 | 封印一，D2发现 | IF DAY == 3；TRANSFER风向标的运动给恶魔。 |
| T02 | 封印二，D3发现 | IF DAY == 5；EXCHANGE电台与恶魔的声音。具体声音交换的表现细节待细化。 |
| T03 | 封印三，D4发现 | IF DAY == 7；TRANSFER太阳的光给恶魔。 |
| T04 | 封印四，D5发现 | IF DAY == 9；赋予恶魔实体，暂以GET表示。精确函数签名与来源待定。 |
| T05 | 前人监听工具，D6正常搜寻 | 玩家补全后启用特殊风铃。监听进入区域的事件，不因报警而推进日期。 |
| T06 | 运动交换/光束牵制工具，D7箱子A内 | 锁定光束和失锁分别触发一次EXCHANGE(MOTION, DEMON, WIND_VANE)，第二次恢复原状态。 |
| T07 | 封印五，D8夜间争夺取得，破碎 | 原IF DAY == 9、OPEN湖中封印，破碎后无效。重构为WHILE DAY <= 9、EXCHANGE(SEAL, BOX_B, LAKE)。 |

不以发现或阅读作为已固化日期程序执行的前提。不将T07原程序的封印目标写成DEMON.SEAL，湖的封闭与恶魔的实体/运动分开。

## 5 时间、条件与固定拓扑

- 一天暂定现实24分钟；每日醒来时间、日长、夜间开放时刻可调。玩家可连续睡到D9，不要求先完成任务。
- IF等待首次满足条件，执行一次后永久结束；不会在第二天重新获得资格。ON在新的指定事件发生时响应，不按帧连续执行。
- 本游戏日期WHILE在范围内每天最多执行一次；零点是当日最早时刻。零点后才完成且条件已满足，立即执行首轮，之后等待下个零点。返回线路不等于即时死循环。
- **删除+1符文、推进一天的功能和固化后的自动加速。** 石板不操作时钟。自然流逝、睡眠和演出调度通过同一个只向前的世界时钟，所有跨越的零点事件必须正常执行。
- T07以当日执行记录去重，不同时被循环与日程再次调用。D9终局停止时钟和后续副作用。

九宫格行优先编号：1=9、2=>=、3=DAY、4空、5=EXCHANGE、6空、7=SEAL、8=BOX_B、9=LAKE。

- IF线路：`3 -> 2 -> 1 -> 5 -> 7 -> 8 -> 9`。
- WHILE在此基础上直接增加`9 -> 3`；不再经过6。返回线路在揭露前已存在，不在结局凭空添加。
- 上排为9 >= DAY，即DAY <= 9。玩家理解为IF，误读点为是否返回继续等待下一日。
- 函数必须位于IF/ON/WHILE等条件结构，不提供裸CALL。TRANSFER转移一单位并检查来源/容量；EXCHANGE交换同一属性的全部值，重复交换恢复。可使用OPEN等专用函数，不要求参数数目一致。
- 不实现自由画线、通用任意语句解释器、同帧高速WHILE或四轮上限。

## 6 工具、密码与追逐的交互规则

### 箱子A

三位密码锁的符号顺序为电台、太阳、风向标。旁边轮盘刻数字并有固定朝向标记；将三个对象的固定方位对应到轮盘数字，再按符号顺序输入。不再用属性生效天数作为密码，不预设旧密码573。具体场地位置/数字由关卡配置决定，风向标的朝向变化不能改变其物体方位答案。

预计D7通过太阳异变自然认出符号，允许提前推理解开，不依赖隐藏D7硬锁或强制玩家看过某事件。T06获得时间可能提前，具体教学与工具限制需在关卡验证。

### T05 监听

补全即启用，不推进日期。风铃对恶魔进入监测区域报警一次；离开后重新待命，停在范围内不反复报警。不同固定位置/音色提供区域线索。响度首先反映玩家到风铃的距离，不能直接宣称是玩家到恶魔的距离；沉默不代表安全。

### T06 光束牵制

持续稳定照住可辨认的脚印/雪雾区域后锁定，不要求瞄准完全不可见的点。锁定只交换一次运动，失锁再交换一次，不能每帧往返。交换时风向标转动、脚印停止；复位时反之。

光束有可调距离、稳定瞄准要求，遮挡、转身或超距失锁。停止运动的恶魔仍可发声干扰。取T07需短暂低头/移开光束，无法同时全程牵制和完成拾取。运动牵制不能撤销实体赋予或封印程序，不会成为阻止D9降临的通用手段。

## 7 编辑与固化

T01至T04、T06已固化；T05与T07需要玩家补全。线路由每块石板自带，玩家只放置、移动符文，预置提示符文可移动；错误可反复尝试。首版接受关卡目标程序，不支持任意自由程序结局。

目标通过后线路熔断，内部程序保留不可变快照，不能再写入。抠下表面符文不中止程序，不提供拆改/停止最终循环的玩法。非目标不固化、不改变世界；合法但非目标的组合不能统一称语法错误。预置、干扰项、BOX/LAKE互换是否接受及T05具体布局仍待细化。

近距离交互后拉近场景镜头，不另造二维解谜世界。按键、移动锁定和机位随现有实现与试玩优化。

## 8 箱子B、时间窗口与结局

SEAL为封闭属性，1封闭、0解封；机械箱盖开合与SEAL分开。A的机械密码不参与B/湖的交换。

| 节点 | BOX_B.SEAL | LAKE.SEAL | 结果 |
| --- | --- | --- | --- |
| D8重构前 | 1 | 0 | B打不开，湖自第一夜一直开启。 |
| D8第一次交换 | 0 | 1 | B解封，湖重新封闭，湖光熄灭。 |
| D9第二次交换 | 1 | 0 | B再次封闭，箱盖猛合，湖光重亮。 |

进入T07夜间争夺/重构段后，为拾取、错误尝试、回棚、开B和阅读保留午夜前时间。这个窗口属于流程演出调度，不是石板能力，不能只从打开文本才开始保留，否则玩家可能拼图时已经跨日。最晚时刻与节奏可调；时间不得倒退。

箱内文字揭示WHILE返回及再次交换的后果，不再教授+1。阅读速度慢或长时间不关闭不能错过零点演出；主动关闭关键记录作为读完/继续的操作，不强迫固定阅读秒数。关闭后保留短暂过渡，再将镜头拉向挂钟，看指针到12点，依次呈现石板发光、箱盖猛合、湖光重亮、实体降临。演出开始后避免重复交互跳过关键状态。

未进入T07流程，可不探索或直接睡到D9。湖本已开启，原OPEN虽破碎，T04仍赋实体并直接降临；不暗中修好石板或添加隐藏OPEN。进入保留窗口后主动睡觉也明确放弃该段，继续正常跳日，不能把玩家锁在D8。

同一零点先完成赋实体与第二次交换，再判定实体且开湖；规则终局与镜头/文字呈现可分离，以保留箱盖和湖光的可见时间。游戏止于D9，不继续D10。

## 9 制作表面与待定

代码负责规则/输入/状态，保存的Scene/Prefab/数据资产负责地图、镜头、静态UI、音频、模型、灯光与调参。需要暴露日长、醒来、T07时段、阅读窗口、镜头、倒计时、牵制距离/稳定时长、风铃半径和追逐参数。占位与正式资产在任务/架构中标明。

仍需细化：T04精确签名与来源，投影影响现实的边界，接班者缺席原因，T05补全布局，声音属性的交换细节，具体探索任务和惊吓脚本，密码轮盘场地/数字，追近打断反馈，醒来表，存档/暂停/设置范围与提交设备。

非首版必做：战斗/伤害/死亡、复杂生存数值、自由绘线、通用编程、多分支安全结局、中止固化循环。原始Word/PDF为来源快照，当前接受的设计以本文件为唯一维护正文，不以旧快照覆盖新决定。
