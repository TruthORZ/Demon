## 1 定位与制作约束

Windows第一人称键鼠雪地恐怖解谜。玩家独自在监测站值守，九天内观察世界、理解符文、使用监测与牵制工具，最后尝试封湖，却因误读循环再次开启封印。保留小屋、工具棚、湖岸、雪林、山洞与邪教仪式方向，不采用无线电求救者身份骗局。

团队为策划一名、技术美术一名，Codex负责程序与技术，用于课程展示。2026-11-10确认本轮无提交日期和目标总游玩时长，不沿用旧的剩余三周排期。本轮要求完整流程、对应演出/音效触发和Windows包验收，允许明确标注的占位资源；正式配音、美术制作及退出后的存档不纳入。

首个可玩版本使用简单几何占位；场景、模型、镜头、UI、材质、音频和可调参数保存为Unity资产。具体展示电脑配置待确认。

## 2 故事、能力与威胁边界

第一夜暴风雪中邪教徒开启湖中封印，五块封印石板散落。恶魔投影能影响现实，但尚无正式降临的实体。玩家原定第八天交班，接班者没有到来，原因待定。

恶魔配合制造第八天争夺T07的假象，不代表它能自行重构石板。投影可影响的具体实物、接触符文与不能自己修复的原因仍待细化。

无玩家伤害、生命值或死亡。恶魔通过巨大雪地脚印、声音、照明干扰和黑影等产生威胁。追近沿用当前的打断拾取、暂时退开和保留进度；任务超时失败独立于追逐。木屋内部为安全区，恶魔不能进入。D3才获得运动，D5才获得声音，D7才获得光；不提前使用对应主动能力。D2跟随的是邪教徒的人类脚印。D3–D7恶魔速度逐日增加但低于玩家奔跑速度，D8起超过奔跑速度；甩开足够距离后会丢失目标，重新发现需遵守侦测规则。速度、侦测/脱离距离与冷却可调，具体数值由试玩确定。

湖中恶魔身影从D3开始显现，初期可在夜间或下雪时偶尔出现，随着能力解封靠近湖岸；D7后常驻。引导符文发光不等于可转移的LIGHT属性。

## 4 七块石板的身份与程序

总编号用于沟通与发现顺序，封印编号只说明五块封印的身份。T07就是第五封印，不额外增加另一块等待OPEN的石板。

| 总编号 | 身份/取得 | 条件与效果 |
| --- | --- | --- |
| T01 | 封印一，D2发现 | IF DAY == 3；TRANSFER风向标的运动给恶魔。 |
| T02 | 封印二，D3发现 | IF DAY == 5；EXCHANGE电台与恶魔的声音。原广播移到湖中恶魔声源，电台啸叫；占位音可替换。 |
| T03 | 封印三，D4发现 | IF DAY == 7；TRANSFER太阳的光给恶魔。 |
| T04 | 封印四，D5发现 | IF DAY == 9；赋予恶魔实体，暂以GET表示。精确函数签名与来源待定。 |
| T05 | 前人监听工具，D6正常搜寻 | 玩家补全后启用特殊风铃。监听进入区域的事件，不因报警而推进日期。 |
| T06 | 运动交换/光束牵制工具，D7箱子A内 | 锁定光束和失锁分别触发一次EXCHANGE(MOTION, DEMON, WIND_VANE)，第二次恢复原状态。 |
| T07 | 封印五，D8夜间争夺取得，破碎 | 原IF DAY == 9、OPEN湖中封印，破碎后无效。重构为WHILE DAY <= 9、EXCHANGE(SEAL, BOX_B, LAKE)。 |

不以发现或阅读作为已固化日期程序执行的前提。不将T07原程序的封印目标写成DEMON.SEAL，湖的封闭与恶魔的实体/运动分开。

## 5 时间、条件与固定拓扑

- 完整24游戏小时对应现实12分钟，即日长720秒；不是从08:00到午夜再额外给12分钟。每日醒来时间、日长、入夜与夜间开放时刻可调。睡觉、自然跨日和超时失败遵守第10节，不能连续睡过关键事项。
- IF等待首次满足条件，执行一次后永久结束；不会在第二天重新获得资格。ON在新的指定事件发生时响应，不按帧连续执行。
- 本游戏日期WHILE在范围内每天最多执行一次；零点是当日最早时刻。零点后才完成且条件已满足，立即执行首轮，之后等待下个零点。返回线路不等于即时死循环。
- **删除+1符文、推进一天的功能和固化后的自动加速。** 石板不操作时钟。自然流逝、睡眠和演出调度通过同一个只向前的世界时钟，所有跨越的零点事件必须正常执行。
- T07以当日执行记录去重，不同时被循环与日程再次调用。D9终局停止时钟和后续副作用。

九宫格行优先编号：1=9、2=>=、3=DAY、4空、5=EXCHANGE、6空、7=SEAL、8/9分别放BOX_B与LAKE，两者顺序不限（BOX_B→LAKE或LAKE→BOX_B都接受）。

- IF线路：`3 -> 2 -> 1 -> 5 -> 7 -> 8 -> 9`。
- WHILE在此基础上直接增加`9 -> 3`；不再经过6。返回线路在揭露前已存在，不在结局凭空添加。
- 上排为9 >= DAY，即DAY <= 9。玩家理解为IF，误读点为是否返回继续等待下一日。
- 函数必须位于IF/ON/WHILE等条件结构，不提供裸CALL。TRANSFER转移一单位并检查来源/容量；EXCHANGE交换同一属性的全部值，重复交换恢复。可使用OPEN等专用函数，不要求参数数目一致。
- 不实现自由画线、通用任意语句解释器、同帧高速WHILE或四轮上限。

## 6 工具、密码与追逐的交互规则

### 箱子A

三位密码锁的符号顺序为电台、太阳、风向标。旁边轮盘刻数字并有固定朝向标记；按三个对象的约定方位对应到轮盘数字，再按符号顺序输入。太阳答案始终使用D7永夜固定后的方位，不随D1–D6天空运动变化；电台/风向标使用固定物体方位。风向标叶片朝向不能改变答案。不再用属性生效天数作为密码，不预设旧密码573。具体场地位置/数字由关卡配置决定。

预计D7通过太阳异变自然认出符号，允许提前推理解开，不依赖隐藏D7硬锁或强制玩家看过某事件。T06获得时间可能提前，具体教学与工具限制需在关卡验证。

D1桌旁普通手电可拾取，无电池消耗；取得T06后在同一手电上增加光束牵制能力。未取T06时照明不能锁定恶魔或交换运动。手电拾取本身不是睡觉门槛，必须保留后续回屋拾取的路径。

### T05 监听

补全即启用，不推进日期。风铃对恶魔进入监测区域报警一次；离开后重新待命，停在范围内不反复报警。不同固定位置/音色提供区域线索。响度首先反映玩家到风铃的距离，不能直接宣称是玩家到恶魔的距离；沉默不代表安全。

### T06 光束牵制

持续稳定照住可辨认的脚印/雪雾区域后锁定，不要求瞄准完全不可见的点。锁定只交换一次运动，失锁再交换一次，不能每帧往返。交换时风向标转动、脚印停止；复位时反之。

光束有可调距离、稳定瞄准要求，遮挡、转身或超距失锁。停止运动的恶魔仍可发声干扰。取T07需短暂低头/移开光束，无法同时全程牵制和完成拾取。运动牵制不能撤销实体赋予或封印程序，不会成为阻止D9降临的通用手段。

## 7 编辑与固化

T01至T04、T06已固化；T05与T07需要玩家补全。线路由每块石板自带，玩家只放置、移动符文，预置提示符文可移动；错误可反复尝试。首版接受关卡目标程序，不支持任意自由程序结局。

目标通过后线路熔断，内部程序保留不可变快照，不能再写入。抠下表面符文不中止程序，不提供拆改/停止最终循环的玩法。非目标不固化、不改变世界；合法但非目标的组合不能统一称语法错误。T07的EXCHANGE为对称交换，第8/9槽BOX_B与LAKE互换同样固化，其他槽位/函数/对象要求不放宽。预置、干扰项及T05具体布局仍待细化。

近距离交互后拉近场景镜头，不另造二维解谜世界。按键、移动锁定和机位随现有实现与试玩优化。

## 8 箱子B、时间窗口与结局

SEAL为封闭属性，1封闭、0解封；机械箱盖开合与SEAL分开。A的机械密码不参与B/湖的交换。

| 节点 | BOX_B.SEAL | LAKE.SEAL | 结果 |
| --- | --- | --- | --- |
| D8重构前 | 1 | 0 | B打不开，湖自第一夜一直开启。 |
| D8第一次交换 | 0 | 1 | B解封，湖重新封闭，湖光熄灭。 |
| D9第二次交换 | 1 | 0 | B再次封闭，箱盖猛合，湖光重亮。 |

进入T07夜间争夺/重构段后，为拾取、错误尝试、回棚、开B和阅读保留午夜前时间。这个窗口属于流程演出调度，不是石板能力，不能只从打开文本才开始保留，否则玩家可能拼图时已经跨日。最晚时刻与节奏可调；时间不得倒退。

箱内文字揭示WHILE返回及再次交换的后果，不再教授+1。阅读速度慢或长时间不关闭不能错过零点演出；主动关闭关键记录作为读完/继续的操作，不强迫固定阅读秒数。关闭后保留短暂过渡，再将镜头拉向挂钟，看指针到12点，依次呈现石板发光、箱盖猛合、湖光重亮、实体降临。演出开始后避免重复交互跳过关键状态。

D8禁止睡觉跳过结局。尚未进入T07保留窗口时，跨日请求若关键事项未完成则当天失败；进入T07流程后沿用前述午夜前时间保护，直到在箱B现场读完并主动关闭关键记录，再允许导演演出推进到D9。此保护是已确认的D8流程安排，不推广到D1–D7。原全睡眠降临路线仅保留为旧测试场景的兼容行为，不是新版雪地主线的玩家路线。

同一零点先完成赋实体与第二次交换，再判定实体且开湖；规则终局与镜头/文字呈现可分离，以保留箱盖和湖光的可见时间。游戏止于D9，不继续D10。

## 9 制作表面与待定

调试天数菜单用于场景验收。跳到第N天时按完整路线补齐前N-1天，包括新版巡查/关键事项及物品记录，目标当天留待体验。支持回退与重复跳转；D8夜间另设待拾取T07入口，D9入口进入零点终局。调试重放与玩家失败重试是不同用途：重试必须恢复玩家实际当天起点，不能用调试重放补发物品或改写前几天选择。调试操作不能成为正常玩家绕过任务门槛的验收依据。

代码负责规则/输入/状态，保存的Scene/Prefab/数据资产负责地图、镜头、静态UI、音频、模型、灯光与调参。需要暴露日长、醒来、T07时段、阅读窗口、镜头、倒计时、牵制距离/稳定时长、风铃半径和追逐参数。占位与正式资产在任务/架构中标明。

仍可迭代且不阻塞本轮计划：T04精确签名与来源，投影影响现实的边界，接班者缺席原因，以及具体文案、素材、布局、醒来表与追逐数值。纸条B先提供少量可替换语言占位说明，不承担隐藏通关条件。展示设备待最终Windows验收时记录。

非首版必做：战斗/伤害/死亡、复杂生存数值、自由绘线、通用编程、多分支安全结局、中止固化循环。原始Word/PDF为来源快照，当前接受的设计以本文件为唯一维护正文，不以旧快照覆盖新决定。

此前轻量切片的实现与验证历史保留在TASK-011至TASK-015；其中“巡查可选、任意睡眠、D5只剩静电”等旧决定已由2026-11-10确认规则替代。沿用的内容为：D2人类脚印到T01，D3大型遗留痕迹到T02，D4仪式遗址T03，D5湖岸T04，D6监听站T05；遗留痕迹不等于移动威胁。D7太阳记录及光束练习仍可提供辅助说明，不新增睡眠门槛；D8交接记录改为等待前置。

四处巡查为电台、风向标、湖畔巡查点、森林巡查点；每天各靠近按E检查一次，按当天状态给出观察文字，任务列表显示进度。重复检查不重复计数，不加入调频或维修操作。纸条B、石板旁说明纸条、普通手电拾取不额外阻止睡觉；它们仍提供对应可收集/可读内容。

D1–D7仅在关键事项全部完成且已入夜时允许睡觉。入夜按世界时刻判断，D7永夜画面不能使白天立即具备睡眠资格。任务全部完成也允许等待自然跨日。一天结束仍有关键事项未完成，先判失败，不能先执行次日零点属性变化再补判；D8沿第8节保护窗口处理。

失败显示原因和未完成事项，暂停玩法，由玩家点击“重试当天”。恢复玩家实际进入当天时的完整快照，包括位置、时间、任务、物品、解谜与恶魔状态；保留前几天取得的内容，撤销当天新变化。自然跨日与睡觉进入当天的时刻可以不同，恢复各自实际入口，不统一伪造为08:00。使用当前游戏进程内的临时记录，退出后不能继续。

## 11 背包和纸条

背包用于重读纸条、石板记录和查看关键道具状态，不设置容量、丢弃、组合或资源负重。纸条互动后自动收录，可反复查看；T01–T04以记录为主，T05/T07仍在场景原有拼板位置操作，T06代表工具解锁。不能通过背包直接远程操作石板、开箱或触发午夜导演。

2026-11-11确认修改：背包使用多格界面，每份纸条、石板记录或道具独占一格，重复取得不重复占格。点击格子在背包内查看对应正文，正文可滚动；空格可见，超过初始格数时扩展，不限制容量。Tab/Esc仍开关背包并暂停世界。

主线手电改为鼠标左键点击切换开关，松开鼠标后保持当前开关状态；右键不再控制主线手电。背包/谜题/阅读中的鼠标操作不能切换手电；关闭界面后也不能把该次点击传给手电。T06仍要求有效、稳定照射，失去照射或关闭手电时恢复运动。挂钟移除秒针，仅保留时针与分针；结局跨午夜流程不变。

D1桌上纸条A介绍四处每日巡查及屋后箱子；纸条B提供少量恶魔语言占位。T01旁说明“第三日，祂将获得运动”；T02旁说明“第五日，祂将获得声音”；T03旁说明“第七日，祂将获得光”；T04旁说明“第九日，祂将获得实体”；T05旁提供监听说明。箱B记录沿用WHILE返回与再次交换真相，现场读完后可收录重读。
